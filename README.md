Desenvolvedor full stack com foco em front-end. Construo aplicações web e portais corporativos desde 2021, com **React, Next.js, TypeScript e Angular** no front-end e **Java/Spring Boot e Node.js** no back-end.

No dia a dia trabalho com componentes reutilizáveis, estado com TanStack Query e Zustand, formulários com React Hook Form e Zod, e APIs REST com Spring Security, JWT e PostgreSQL.
